ARLO V1.2 — FINAL MERGED BUILD

تم دمج KRONO V3.1 مع الهوية البصرية الجديدة (كريمي + بني داكن + ذهبي) ومع إصلاحات V3.2.

أهم ما تم تغييره:
01) Responsive / Mobile-first: الواجهة تتكيف مع مقاسات الشاشات المختلفة وSafe Area للموبايل.
02) الرسائل: الضغط على الشخص يفتح محادثة مستقلة على الموبايل بدل ظهور المحادثة أسفل القائمة، مع أزرار مكالمة صوتية وفيديو.
03) الملف الشخصي: صورة دائرية + غلاف + تاريخ الميلاد + خصوصية البريد.
04) الخصوصية: البريد مخفي افتراضيًا، وأسماء المشاهدين لا تظهر إلا لصاحب المحتوى.
05) رقم الهاتف في التسجيل ما زال اختياريًا.
06) الأيقونات الرئيسية أعيد تصميمها كـ CSS icons بدل الاعتماد على إيموجي الواجهة الأساسية.
07) زر الرجوع في Android أصبح يتعامل مع سجل الصفحات/المحادثة قبل الخروج.
08) القصص والمنشورات: رفع صورة/فيديو/صوت مع شريط تقدم، ومعاينة، وأخطاء واضحة بدل البقاء على "جاري النشر".
09) الهوية: ARLO V1.2 بالألوان الكريمي والبني والذهبي، بدون الأزرق كلون أساسي.
10) مشكلة تحديد أسماء المستخدمين باللون الأزرق: العناصر التفاعلية أصبحت أزرار/عناصر قابلة للنقر مع user-select:none، مع إبقاء نص المنشور قابلًا للنسخ.
11) زر التفاعل أصبح في صف واحد مع التعليق والحفظ والمشاركة، وتفاصيل المشاهدين لصاحب المنشور فقط.
12) مساعد Arlo أصبح يعمل محليًا بدون API ويعطي إجابات مرتبطة بمشاكل واستخدام KRONO. هذا ليس نموذجًا توليديًا خارجيًا؛ ربط AI حقيقي يحتاج API/Backend.
13) رفع Firebase Storage أصبح Resumable مع نسبة تقدم، وتم إضافة fallback لمعرّف الملف بدل الاعتماد على crypto.randomUUID فقط.

ملاحظة مهمة:
إذا ظهر خطأ في رفع الصور/الفيديو بعد البناء، راجع Firebase Storage Rules. يوجد مثال في storage.rules.example، لكن لا تقم بنشره قبل مراجعته بما يتوافق مع قواعد مشروعك.

مكالمات الفيديو/الصوت:
الواجهة موجودة، لكن الاتصال الحقيقي بين مستخدمين يحتاج WebRTC signaling (مثل Firestore/Realtime Database أو خدمة اتصالات).


V3.2.1 UI change: removed the inline post publisher from the home feed. The bottom-center + button is now the single entry point for creating a post; it opens the post composer modal with text, image/video, preview, remove-media, and publish controls.


V3.2.2 تعديل واجهة الخلاصة: المنشورات تظهر أولاً، والقصص تظهر تحت المنشورات. زر + «إنشاء» في أسفل الشاشة هو المدخل الأساسي لإنشاء ونشر المنشورات. زر «+ قصتك» داخل قسم القصص مخصص للقصص فقط.


V3.2.4 FIX NOTES
- إصلاح خطأ fillProfile عندما يكون عنصر homeAvatar غير موجود في الصفحة.
- جعل تحديث بيانات الملف الشخصي null-safe حتى لا يوقف showApp وباقي تحميل المنشورات.
- إضافة onError لمستمع منشورات Firestore مع رسالة واضحة عند فشل التحميل.
- إذا ظهر ERR_BLOCKED_BY_CLIENT في المتصفح، اختبر الصفحة مع تعطيل AdBlock/Privacy extensions أو حماية التتبع للصفحة؛ هذا الحظر من المتصفح وليس من كود عرض المنشورات.
