ARLO V1.3.6 — Messaging Polish

Changes:
- Desktop message list remains visible beside the active conversation.
- Clicking a person opens the conversation without removing other conversations.
- Cleaner line-style message composer icons for emoji, attachment, microphone and send.
- Emoji picker remains available inside the composer and expands into a full picker.
- Attachment menu remains available for image, video, audio and file selection.
- Preserves Arlo brown/gold branding and the expanded desktop bottom navigation.
