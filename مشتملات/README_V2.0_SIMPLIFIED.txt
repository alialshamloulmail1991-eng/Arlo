KRONO V2.0 — Simplified Social Platform
========================================
هذه النسخة مبنية على V1.9 مع الحفاظ على الملفات والوظائف الأساسية.

أهم تعديلات V2.0:
- واجهة أبسط بدون ذكر أسماء منصات أخرى.
- فيديوهات قصيرة + فيديوهات طويلة داخل KRONO.
- قنوات ومجتمعات داخل KRONO.
- الرسائل تعرض كل المستخدمين الآخرين مباشرة من صفحة الرسائل.
- يمكن فتح محادثة مباشرة من قائمة الرسائل.
- الرسائل المرسلة تظهر بعلامة ✓.
- طلب الصداقة يظهر حالته: أصدقاء / تم الإرسال / طلب وارد، ولا يمكن إرسال الطلب مرة أخرى.
- قبول الطلب لا ينشئ طلبًا جديدًا تلقائيًا.
- إعداد خصوصية جديد لإظهار/إخفاء البريد الإلكتروني للآخرين.
- الحفاظ على وضع توفير البيانات والتحميل التدريجي.
- V1.9 لم يتم تعديلها داخل هذه الحزمة؛ هذه نسخة منفصلة للتطوير.

ملاحظة:
بعض الميزات الكبيرة مثل مكالمات الصوت/الفيديو، البث المباشر، الإشعارات الفورية الكاملة، وقراءة الرسائل تحتاج خدمات Backend إضافية وقواعد Firebase مناسبة قبل الإطلاق العام.
