ARLO V1.3.3 — Messaging UX Update

- Desktop messaging uses a persistent conversation list on the side while the active chat occupies the rest of the screen.
- Mobile messaging switches to a normal full-screen chat with back navigation.
- Clicking a person in the conversation list opens the chat directly; the list remains available on desktop.
- Chat header uses dedicated line-style voice call, video call, and menu icons.
- Emoji button opens a full emoji panel; selecting an emoji inserts it into the message input.
- Attachment button opens options for image, video, audio clip, and file.
- Image, video, audio and generic files can be sent through Firebase Storage.
- Voice messages remain supported through microphone recording.
