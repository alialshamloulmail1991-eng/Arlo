ARLO V1.3

Messaging update:
- Desktop two-pane chat layout inspired by modern web messengers.
- Clicking a person opens the conversation directly.
- Person settings/info are opened only from the dedicated chat info/menu button.
- Added voice/video call buttons and chat info/settings panel.
- Added chat search, attachment entry point, emoji entry point, voice-message button and send button.
- Mobile keeps a full-screen chat experience.
- Existing Arlo brand colors, logo, stories/posts, reactions, profile, communities, channels and AI features remain in the project.
