KRONO V2.0 — المنصة الاجتماعية المصرية

تم بناء V2.0 على V1.9 مع الحفاظ على الوظائف القديمة.

الإضافات الأساسية:
1) مركز اجتماعي واحد يجمع الخلاصة والمنشورات والتفاعلات والقصص والرسائل والفيديوهات القصيرة والمشاهدة والقنوات والمجتمعات.
2) KRONO Shorts لفيديوهات قصيرة مع عدم التشغيل التلقائي.
3) KRONO Watch لعرض الفيديوهات من نفس منظومة المنشورات.
4) قنوات KRONO ومجتمعات KRONO مع إنشاء وانضمام مبدئي عبر Firestore.
5) متابعة الحسابات بالإضافة إلى الصداقة والمراسلة.
6) وضع توفير البيانات مفعّل افتراضيًا.
7) الخلاصة والقصص محدودة بـ30 عنصرًا بدل تحميل المجموعة كاملة لحظيًا.
8) الصور الكبيرة تُضغط في المتصفح قبل رفعها إلى Firebase Storage.
9) الفيديو لا يبدأ تلقائيًا ويستخدم preload=none لتقليل استهلاك البيانات.
10) الملفات الأكبر من 60MB تُرفض لتقليل استهلاك التخزين والرفع.

مهم:
- V1.9 لم تُحذف؛ هذا الإصدار مبني عليها.
- الميزات التي تحتاج خدمات مستقلة مثل بث مباشر حقيقي، مكالمات صوت/فيديو، توصيات خوارزمية متقدمة، وكاتالوج موسيقى مرخّص تحتاج Backend وخدمات إضافية قبل الإطلاق العام.
- قبل النشر العام يجب مراجعة قواعد Firestore/Storage، أذونات المستخدمين، وسياسة الخصوصية.
