ARLO V1.3.5
===========
Desktop messaging navigation update.

When the user opens Messages on a desktop/laptop:
- The bottom navigation remains visible instead of being hidden.
- The bottom navigation expands and its icons become larger.
- The Messages item is highlighted.
- Home, Communities, Create, Messages and Profile remain directly accessible.
- The Create (+) button remains prominent.
- The messaging area is resized so the enlarged navigation does not cover the conversation.

Mobile messaging behavior from V1.3.4 remains unchanged.
